# GPU ML Platform on Kubernetes

This project demonstrates the design and implementation of a production-ready
Machine Learning platform running GPU workloads on Kubernetes.

## Goals
- Provision cloud infrastructure using Infrastructure as Code (Terraform)
- Run Kubernetes clusters with GPU-enabled nodes
- Train and serve ML models using PyTorch
- Orchestrate ML pipelines
- Focus on scalability, cost optimization and observability

## Tech Stack
- Terraform
- Kubernetes (EKS)
- Python
- PyTorch
- Docker
- GPU (CUDA)
- Prometheus & Grafana (later stages)
